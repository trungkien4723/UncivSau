## Key Tech Tree Prerequisites (Simplified)

### Ancient → Classical
- **Pottery** → Writing, Irrigation
- **Animal Husbandry** → Archery
- **Mining** → Masonry, Bronze Working, Wheel
- **Sailing** → Shipbuilding, Celestial Navigation
- **Astrology** → Celestial Navigation
- **Irrigation** → Writing
- **Writing** → Currency
- **Archery** → Horseback Riding
- **Masonry** → Construction
- **Bronze Working** → Iron Working
- **Wheel** → Engineering

### Classical → Medieval
- **Celestial Navigation** → Currency, Shipbuilding
- **Currency** → Mathematics, Apprenticeship
- **Horseback Riding** → Construction, Apprenticeship, Stirrups
- **Iron Working** → Machinery
- **Shipbuilding** → Buttress
- **Mathematics** → Military Tactics, Education, Buttress
- **Construction** → Castles, Military Engineering
- **Engineering** → Machinery

### Medieval → Renaissance
- **Military Tactics** → Mass Production
- **Buttress** → Cartography, Mass Production
- **Apprenticeship** → Education, Military Science, Machinery
- **Education** → Printing, Astronomy, Banking
- **Cartography** → Square Rigging, Steam Power
- **Mass Production** → Ballistics, Industrialization
- **Machinery** → Printing, Ballistics
- **Castles** → Military Engineering, Siege Tactics

### Renaissance → Industrial
- **Printing** → Astronomy, Banking
- **Astronomy** → Square Rigging
- **Gunpowder** → Military Science, Ballistics, Rifling
- **Banking** → Economics, Mercantilism
- **Square Rigging** → Steam Power
- **Ballistics** → Steam Power, Military Science

### Industrial → Modern
- **Steam Power** → Combustion, Flight
- **Military Science** → Rifling, Combustion
- **Rifling** → Replaceable Parts, Steel
- **Industrialization** → Combustion, Electricity
- **Economics** → Mercantilism, Corporations
- **Mercantilism** → Economics, Corporations
- **Chemistry** → Replaceable Parts, Steel
- **Ballistics** → Advanced Ballistics, Rocketry

### Modern → Atomic
- **Combustion** → Synthetic Materials, Advanced Flight
- **Electricity** → Radio, Nuclear Fission
- **Replaceable Parts** → Synthetic Materials, Composites, Plastics
- **Radio** → Computers, Advanced Flight
- **Chemistry** → Plastics, Composites
- **Rifling** → Replaceable Parts, Steel

### Atomic → Information
- **Advanced Ballistics** → Lasers, Stealth Technology
- **Synthetic Materials** → Composites, Advanced Flight
- **Nuclear Fission** → Nuclear Fusion, Particle Physics
- **Computers** → Lasers, Stealth Technology, Cybernetics
- **Composites** → Stealth Technology
- **Flight** → Advanced Flight, Aerodynamics

### Information → Future
- **Lasers**, **Stealth Technology**, **Satellites**, **Nuclear Fusion**, **Advanced Flight**, **Nanotechnology** → Future Tech (repeatable)

## Notes

- **GS** = Requires Gathering Storm expansion
- **R&F** = Requires Rise and Fall expansion
- **NFP** = Requires New Frontier Pass
- Eureka boosts provide **40%** of the tech cost instantly when triggered
- Tech costs scale with game speed, map size, and difficulty
- The tech tree allows **multiple paths** - you don't need all prerequisites to research a tech
- Some technologies have different costs/eurekas in different expansions
- This data reflects the complete Civ 6 tech tree including all DLCs
